# 完善缺陷路线图：吸取竞品优点 → 修复自身短板

> 依据：`docs/市场竞品分析报告.md`（15 家竞品，全部标注【已查证】/【厂商宣称】/【未获取】）× `docs/全学段扩展计划.md`（P0 平台化底座 → P1 中学 → P2 小学 → P3 多校）
> 原则：**先补门槛项（P0 底座同步做，成本最低）→ 再做差异化（P1/P2 快速见效）→ 最后商业化（P3）**
> 每项闭环：实现 → 单测 → 全量测试 → README 同步 → git 提交

## 二、P0 阶段任务卡（与平台化底座同步，大学现状零回归）

> P0 期间所有改动必须保持现有大学功能行为不变；每张卡独立提交。

| # | 任务卡 | 涉及范围（映射现有代码） | 验收标准（完成 = 全部满足） |
|---|---|---|---|
| P0-1 | 等级赋分模块 | `ScoreNormalizer`（新）：原始分→等级→赋分；`score` 表增 `score_type`/`standard_score` | ① 公式可配置（3+1+2/3+3 预设模板）② 单测 ≥3 例（换算边界）③ 全量测试通过 |
| P0-2 | 规则/指标学段化 | `rule_template`/`metric_def` 表按 stage 实例化；现有预警规则迁移为模板实例 | ① 大学段默认模板与现状行为一致（回归测试）② 新增学段可通过配置启用新指标 ③ 阈值可配置入库 |
| P0-3 | 风险分级标准化 | 预警等级枚举扩展（对齐金智五级赋值）；处置动作/责任角色绑定 | ① 触发条件→处置动作→责任角色落库 ② 监察中心/工单按级联动 ③ 单测覆盖分级转换 |
| P0-4 | K12 合规前置 | `guardian_consent` 生效；敏感字段脱敏标记；数据留存期限配置；合规清单文档 | ① 监护人同意字段接入家长端注册/绑定流 ② 看板/导出脱敏规则 ③ 教育 App 双备案/等保启动检查清单 |
| P0-5 | NL2Query 强化 | 现有 NL 查询扩展学段化指标 + 自动图表输出 + 数据边界 | ① 跨学段指标可查询 ② 返回含图表配置 ③ 越权查询被拒绝（隔离测试） |
| P0-6 | 组织树抽象 | `org_node` 设计预留 `school_id`/租户位；现有 college→major→clazz 迁移 | ① 大学语义数据零丢失 ② P3 多校字段预留 ③ 迁移后全量测试通过 |

## 五、排序依据与风险

1. **P0 六项全部为「底座改动」，越早做成本越低**：赋分/学段化模板/合规前置三项与扩展计划 P0 改造点直接咬合，改动最小；拖到 P1/P2 再做会产生返工（组织树、score 表结构、规则模板均会被后续阶段依赖）。
2. **差异化窗口**：竞品收缩期（极课 2026-08-31 停服、好分数经营困难、Blackboard 破产重组、希沃硬件收入 -8.75%）内完成 P0→P1，可承接释放的存量学校市场。
3. **风险提示**：
   - 竞品覆盖数/市占率均为厂商口径（智学网 1.3 万 vs 3 万所、强智 800/900/1000+），引用须标注口径；
   - 等级赋分算法竞品均未公开（【未获取】），我方赋分公式须按教育部选科赋分规则自行实现并可配置，不与竞品比对数值；
   - 好分数/七天/升学 e 网通三类「家长收费被点名」反例表明：C 端收费必须坚持「基础免费 + 增值自愿」。
