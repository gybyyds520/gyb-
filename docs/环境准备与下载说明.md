# 环境准备与下载说明（Installation & Download Guide）

本系统「基于 Ollama 的高校学情预测分析系统」启动前需要准备的基础软件、依赖与模型文件。
按下列顺序安装即可完整运行 **后端 + 前端 + 桌面端 + ML 预测 + OCR 试卷识别 + SD 激励卡绘图 + 本地大模型** 全部功能。

> 设计原则：全部依赖**本地离线 / 免费**；唯一可选联网项是「云端 AI 降级通道」，不配置也完全不影响运行。

---

## 一、必装基础软件（手动下载安装一次）

| 软件 | 版本要求 | 下载地址 | 说明 |
|---|---|---|---|
| JDK | 17+（推荐 17/21） | https://adoptium.net | 后端 Spring Boot 3.2.5 运行环境 |
| Node.js | 18+（推荐 20 LTS） | https://nodejs.org | 前端 Vite 6 构建 |
| MySQL | 8.0+ | https://dev.mysql.com/downloads/mysql | 业务数据库，本地 root 密码示例为 `123456` |
| Python | 3.11 ~ 3.13 | https://www.python.org/downloads | ML 预测 / OCR / SD 绘图服务 |
| Ollama | 最新版 | https://ollama.com/download | 本地大模型运行时（Windows 一键安装） |
| Git | 任意 | https://git-scm.com | 拉取代码 / 版本管理（可选） |

## 二、本地大模型下载（Ollama，必装）

安装 Ollama 后，打开命令行执行：

```bash
ollama serve                     # 先启动服务（Windows 安装后常驻）
ollama pull deepseek-r1:7b       # 主力推理模型（约 4.7GB）
ollama pull deepseek-r1:1.5b     # 降级备选模型（约 1.1GB）
ollama pull nomic-embed-text     # 知识库向量化模型（约 274MB）
```

- 对应后端配置（`server/src/main/resources/application.yml`）：
  - `xqfx.ollama.primary-model: deepseek-r1:7b`（学情智能体、归因、评语等主力）
  - `xqfx.ollama.fallback-model: deepseek-r1:1.5b`（本地降级）
  - `xqfx.ollama.embed-model: nomic-embed-text`（RAG 向量检索）
- 模型不在本地时，相关 AI 功能会自动降级为规则化文本，系统其余功能不受影响。

## 三、数据库初始化

```bash
# 进入项目 sql 目录
mysql -u root -p123456 < sql/schema.sql        # 建表（48 张）
mysql -u root -p123456 < sql/seed_base.sql     # 基础数据（学院/专业/课程等）
mysql -u root -p123456 < sql/schema_phase2.sql # 增量表（按 2~13 逐个执行，共 48+ 张）
```

> ⚠️ Windows 下 SQL 文件含 UTF-8 BOM，直接 `mysql < file.sql` 可能报语法错误，
> 需先去 BOM（PowerShell：`[IO.File]::WriteAllText($dst, $txt.TrimStart([char]0xFEFF), New-Object Text.UTF8Encoding($false))`），
> 或改用 `mysql -e "source 文件路径"`（注意 Windows 下 source 需正斜杠路径）。
> 首次启动后端还会自动执行**启动实时初始化**（空库自动生成演示数据 200 名学生 + 实时模拟流），即使不执行 seed 也能看到演示效果。

初始管理员：`admin / admin123`；其余演示账号（密码 `123456`）：教师 `T001`~`T012`、学生 `2300000001`（共 50 个）、家长 `2300000001P1`。

## 七、Python 预测服务（ml，端口 8000）

```bash
cd ml
python -m venv .venv                 # 建议独立虚拟环境（本机实测 Python 3.13）
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python run.py        # 监听 http://127.0.0.1:8000
```

依赖（`ml/requirements.txt`）：fastapi / uvicorn / pydantic / numpy / pandas / scikit-learn / joblib / xgboost。
训练与推理完全本地，**无需下载模型权重**（随机森林等模型首次训练自动生成到 `ml/models/`，或由后端冷启动兜底）。

## 八、试卷录入 OCR 服务（server/.ocr_venv，端口随后端）

试卷录入（图片 / 扫描 PDF / Word → 文本）使用 **RapidOCR（onnxruntime）**，模型内置、首次 OCR 秒级加载：

```bash
cd server
python -m venv .ocr_venv
.\.ocr_venv\Scripts\pip install rapidocr-onnxruntime onnxruntime python-docx pymupdf
```

- 后端启动时按需加载该虚拟环境；OCR 与文本提取全部**本地离线**，不调用外部接口。
- 若此环境缺失，试卷录入功能会提示错误，不影响系统其他功能。

## 九、成长激励卡 SD 绘图服务（ml/.sd_venv，端口 8001）⭐ 重点

「成长激励卡」由本地 Stable Diffusion（sd-turbo）离线生成海报。需要额外下载 **PyTorch（CUDA 版）+ 模型权重（约 6GB 总量）**：

### 1) 创建虚拟环境 + 安装 Python 依赖

```bash
cd ml
python -m venv .sd_venv
# 依赖清单：ml/sd_requirements.txt（diffusers/transformers/accelerate/safetensors/pillow/huggingface_hub/fastapi/uvicorn 等）
.\.sd_venv\Scripts\pip install -r sd_requirements.txt
```

### 2) 安装 PyTorch（CUDA 12.8 版，约 2.6GB）⚠️ 国内镜像不可用

实测：清华/阿里云/腾讯/北外/中科大镜像对 `cu128 + Python 3.13` 的 torch wheel **均不可用**（404 / 流中断 / 403）。
**唯一可用路径**：PyTorch 官方源，带浏览器 UA 下载 wheel 后本地安装：

```powershell
# 1) 用浏览器 UA 下载（约 0.9MB/s，需要一些时间）
curl.exe -L -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64)" `
  -o torch.whl "https://download.pytorch.org/whl/cu128/torch-2.11.0%2Bcu128-cp313-cp313-win_amd64.whl"

# 2) 本地安装（不装依赖，避免 pip 误选 CPU 版）
.\.sd_venv\Scripts\pip install --no-deps .\torch.whl

# 3) 可选：torchvision（sd-turbo 不强制，缺它仅提示 fallback）
# .\.sd_venv\Scripts\pip install torchvision --index-url https://download.pytorch.org/whl/cu128
```

验证 GPU 可用：

```python
.\.sd_venv\Scripts\python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
# 预期：2.11.0+cu128 True（NVIDIA 显卡；无 NVIDIA 卡可用 CPU 版，速度较慢）
```

> ⚠️ 若此前误装过 CPU 版 torch，先 `pip uninstall torch` 再装 CUDA 版。

### 3) 下载 sd-turbo 模型权重（约 3.3GB）

项目提供断点续传下载脚本 `ml/download_model.py`（hf-mirror.com/stabilityai/sd-turbo）：

```powershell
.\.sd_venv\Scripts\python download_model.py
```

模型落地 `ml/sd-models/sd-turbo/`，包含 text_encoder（约 1.3GB）+ unet fp16（约 1.65GB）+ vae（约 0.32GB）等 12 个文件。

> ⚠️ 关键坑：unet 权重文件名是 `diffusion_pytorch_model.fp16.safetensors`，diffusers 找不到默认名，**需复制一份为 `diffusion_pytorch_model.safetensors`**（脚本会自动处理）。
> `feature_extractor/preprocessor_config.json` 在镜像站 404 属正常，sd-turbo 不使用它，可忽略。

### 4) 启动 SD 服务

```powershell
cd ml
.\.sd_venv\Scripts\python run_sd.py --port 8001      # 监听 http://127.0.0.1:8001
# 健康检查：http://127.0.0.1:8001/health → {"status":"UP","device":"cuda","model_loaded":true}
```

启动顺序：**先启动 SD 服务（8001），再启动后端（8080）**。SD 不可用时后端返回明确错误提示，不影响其他功能。
实测生成速度：首次（含模型加载）约 10 秒，之后单张约 0.7 秒（RTX 4060 Laptop）。

## 十一、云端 AI 降级通道（可选，唯一联网项）

本地 Ollama 不可用时，可自动降级到云端大模型（默认**智谱开放平台 GLM-4.7-Flash，输入/输出/缓存长期免费**）：

1. 注册 https://open.bigmodel.cn → 控制台创建 API Key
2. 注入环境变量（**不落配置文件、不进 git**）：

```powershell
[Environment]::SetEnvironmentVariable('XQFX_LLM_API_KEY', '<你的Key>', 'User')
```

3. 重启后端。`GET /api/ai/health` 会显示 `cloudConfigured: true / cloudAvailable: true`。
4. 也可切换 DeepSeek（`https://api.deepseek.com/v1` + `deepseek-chat`，按量付费）或通义（`https://dashscope.aliyuncs.com/compatible-mode/v1` + `qwen-turbo`），修改 `application.yml` 的 `xqfx.llm.cloud.*` 注释示例即可。
5. 未配置 api-key 时云端通道自动关闭，行为与纯本地完全一致（零风险）。

## 十二、启动顺序速查（完整演示环境）

```text
1. 启动 MySQL          → mysql 服务
2. 启动 Ollama         → ollama serve（已 pull deepseek-r1:7b 等模型）
3. 启动 SD 服务(8001)  → ml\.sd_venv\Scripts\python run_sd.py --port 8001
4. 启动 ML 预测(8000)  → ml\.venv\Scripts\python run.py
5. 启动后端(8080)      → cd server; .\mvnw.cmd spring-boot:run
6. 启动前端(5173)      → cd web; npm run dev
7. 登录演示账号        → admin/admin123 或 T001/123456（教师）、2300000001/123456（学生）、2300000001P1/123456（家长）
```

各服务均为独立进程，可按需只启动一部分；缺某个服务时对应功能报错或降级，不影响其余模块。
