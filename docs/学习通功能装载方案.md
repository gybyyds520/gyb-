# 学习通（超星）功能装载方案

> 目标：学习超星学习通的移动教学便利性，把"课程空间聚合 + 一键签到 + 即测即评"等体验装载进本项目（高校学情分析预警系统），与本项目"学情分析 + 本地 AI + 三端协同"定位契合。
> 调研来源：超星学习通官方使用手册与多所高校（西电/豫章/上海戏剧/中国矿大/长春工大/嘉应/浙江海洋/福州大学）教务处发布的《超星学习通使用指南》教师版/学生版。

## 一、学习通主要功能盘点

| 模块 | 功能 | 教师端能力 | 学生端能力 |
|---|---|---|---|
| **课程空间** | 创建课程、课程目录（章节） | 建课/编辑章节/学生管理 | 我的课程、章节任务导航 |
| **课堂活动-签到** | 普通/手势/位置/二维码 4 种 | 发起签到、实时统计、随时发放/定时发放 | 一键签到、查看统计 |
| **课堂活动-互动** | 投票/问卷、抢答、选人（随机点名） | 发起、结果投屏、按表现打分 | 参与作答 |
| **作业/考试** | 在线作业、章节测验、限时考试 | 布置/批改/统计 | 收到提醒一键作答、查看成绩 |
| **讨论区** | 话题讨论 | 发起、置顶、点赞、评分 | 发帖/回复/点赞 |
| **课程资料** | 课件/文档/视频上传 | 上传、按章节组织 | 查看、下载 |
| **通知公告** | 课程公告/活动提醒 | 发公告、自动提醒 | 收到站内/推送提醒 |
| **数据统计** | 学习时长、任务完成度、成绩 | 学情统计 | 个人学习轨迹 |
| **班级群聊** | 课程群聊 | 群管理 | 群聊 |
| **学习激励** | 积分/经验值 | 规则配置 | 积分累计 |

## 二、装载映射（本项目做 / 借鉴 / 不复制）

| 学习通能力 | 本项目决策 | 理由与落地位置 |
|---|---|---|
| 课程空间（建课/章节） | ✅ 做（第一批） | 基于已有 `course_offering`（教学班）+ 新增 `course_chapter` 章节表，教师端「课程空间」、学生端「我的课程」聚合 |
| 签到（4 种） | ✅ 做（第一批） | 采用"数字码签到"（最实用），签到记录直接写入已有 `attendance` 考勤表（status=PRESENT），与考勤预警打通；支持教师手动补签 |
| 作业/章节测验 | ✅ 做（第一批） | 复用 `homework` 作业引擎（自动判分 + 错题本联动已就绪），加 `course_offering_id` 归属课程空间 + JUDGE 题型支持，学习通式"即测即评" |
| 课程资料 | ✅ 做（第一批） | 新增 `course_material`，按章节上传共享（doc/pdf/ppt/图片），学生端查看下载 |
| 讨论区 | ✅ 做（第一批） | 新增 `course_discussion`（帖/回复/点赞/置顶），教师可置顶 |
| 投票/问卷、抢答、选人 | 🔜 借鉴（第二批） | 与课堂表现 `class_performance` 打通，随机点名→课堂表现记录 |
| 通知/公告 | 🔄 复用现有 | 通知中心已具备，签到/测验/作业发站内提醒 |
| 班级群聊 | 🔄 复用现有 | 站内通讯已实现教师↔学生↔家长 |
| 学习时长/任务完成度 | 🔜 借鉴（第二批） | 统计学生资料查看/签到/测验完成 → 学情分析素材 |
| 积分/经验值 | ❌ 暂不复制 | 非本系统定位，会员体系已覆盖激励 |
| 直播/投屏 | ❌ 不复制 | 依赖第三方直播能力，超出本地部署范围 |

## 三、第一批数据闭环设计

```
课程空间（course_offering + course_chapter）
 ├─ 章节测验（homework 复用：单选/多选/填空/判断/简答）
 │    └→ 学生作答 → 客观题自动判分 → 成绩入统计 → 错题自动入错题本 → 举一反三
 ├─ 课堂签到（attendance：数字码签到 → PRESENT 入考勤）
 │    └→ 考勤率进预警指标
 ├─ 课程资料（course_material 按章节上传）
 └─ 讨论区（course_discussion 帖/回复/点赞/置顶）
全部动作 → 站内通知提醒对应端（复用 notify_message）
```

## 四、新表设计（第一批）

- `course_chapter`：章节（offering_id/序号/标题/说明/排序）
- `course_material`：资料（offering_id/chapter_id/文件名/类型/大小/路径/上传人）
- `course_discussion`：讨论帖（offering_id/作者/内容/置顶/点赞数/回复数）+ `course_discussion_reply`（回复）
- `attendance` 复用；`homework` 增加 `course_offering_id` 列（章节测验归属）

## 五、第一批实施清单（本方案配套代码）

1. 建表：course_chapter / course_material / course_discussion / course_discussion_reply；homework 加列
2. 后端 CourseSpaceController（教师+学生端）：
   - 我的课程（教师：所授教学班；学生：所在班级的课程）
   - 章节 CRUD、资料上传/列表/下载、讨论帖/回复/点赞/置顶
3. 签到 CheckinController：发起数字码签到 → 学生输码签到 → 入 attendance → 通知学生
4. 章节测验：HomeworkService 扩展 `course_offering_id` + JUDGE 题型；教师端从题库选题组测验、学生端课程内作答
5. 前端：
   - 教师端「课程空间」页（课程列表→课程详情 Tab：章节/资料/签到/测验/讨论）
   - 学生端「我的课程」页（课程列表→任务中心：章节/测验/签到/资料/讨论）
   - 菜单：教师 `COURSE_SPACE`（data 组）、学生「我的课程」
6. 测试：单测 + 端到端（教师建章节/发签到→学生签到入考勤→组章节测验→学生作答自动判分→错题联动）
7. README 同步 + git 提交

## 六、第二批待指令（投票问卷 / 抢答 / 随机点名 / 学习时长统计）

与课堂表现打通：随机点名/抢答结果写入 `class_performance`；学习时长统计（资料查看时长+测验完成度）作为学情画像输入。
