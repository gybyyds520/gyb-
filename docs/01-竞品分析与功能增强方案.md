# 竞品分析与功能增强方案

> 课题：基于 Ollama 大模型的高校学情预测分析系统的设计与实现
> 编制日期：2026-10-17
> 目的：调研市面上同类产品，提取可复用的成熟设计，形成本系统的功能增强清单

## 一、竞品调研范围与对象

按产品形态划分为 4 类，共调研 10+ 个代表性对象：

| 类别 | 代表产品 | 定位 |
|---|---|---|
| A. 智慧校园厂商画像平台 | 强智科技「数智画像系统」、新开普「校级大数据分析平台」、武汉启明泰和「高校教研大数据分析系统」、慧萌软件「学生画像分析系统」、江苏捷成睿创「学生画像」 | 面向校方交付的重型平台，功能模块最完整 |
| B. 在线教学平台自带学情分析 | 超星（泛雅/一平三端）、智慧树、雨课堂 | 依托课程与作业数据做教学侧学情分析 |
| C. 学生工作预警系统 | 中国大学生在线「学生预警系统」、各类学工大数据平台 | 以消费/门禁/请销假等行为数据驱动的预警 |
| D. 高校自建 AI 教育应用 | 许昌学院「学生画像」、广西师大「独秀智慧教育学生画像系统」、北邮「比特 Byte 学科大模型」、华东师大「启创 InnoSpark」 | 大模型时代的新形态，代表技术方向 |

## 二、竞品核心能力拆解

### 2.1 启明泰和「高校教研大数据分析系统」（功能最完整，重点对标）

核心功能：
- **群体动态画像**：动态描绘"学生""教师"群体特征，支撑分群施教与分群管理
- **动态学情跟踪与预警**：实时跟踪出勤率、课堂参与度、作业完成率与优秀率，做**学业趋势预测、作业抄袭预警、挂科预警**
- **命题质量分析**：单卷单题的**难度、区分度、得分率、错题对应知识点**分析
- **学生成绩分析**：个人各科在班级/年级的位置与变化趋势、**知识点强弱分析、偏科分析、学业预测值与实际结果对比**
- **教师成绩分析**：班级总体得分率、各难度题目作答情况、错题-知识点分析、跨班对比
- **院级/校级管理者分析**：公共课/核心课程按科次、平均分分布、学科、学院、教师、班级**多维交错分析**
- **数据下钻**：对异常预警"抽丝剥茧、逐层深入"
- **随时随地**：微信业务通知、审批待办
- **API 集成**：与教务系统及第三方系统对接

### 2.2 强智科技「数智画像系统」

- 画像维度：**主修学业成绩、其他成绩、学业预警、学习行为、校园生活**
- 围绕培养方案分析**毕业要求学分进度达成情况、累计未获学分**
- 强调"可查询、可分析、可追踪、可复盘"的成长档案
- 与智慧教学一体化平台、校内多平台深度数据融合

### 2.3 新开普「校级大数据分析平台」

- 建立多种预警模型，通过**学生行为轨迹**分析失联、夜归、逃课、学业、消费、心理等风险
- 特点：**预警维度超出学业范畴**，覆盖生活与心理

### 2.4 中国大学生在线「学生预警系统」

- 整合学业、生活、行为、第二课堂、就业**全维度数据**
- 数据源：一卡通消费、闸机门禁、请销假、课程签到、课程成绩、参加活动
- 产出：画像分析、成长报告、舆情分析、趋势预警、各类预警清单

### 2.5 校方自建典型案例（预警闭环标杆）

**许昌学院三级学业预警机制**（最值得借鉴的闭环设计）：
- 预警分级：**黄牌 / 橙牌 / 红牌**三级
- 学生登录系统后自动弹出预警信息
- 系统从**"导学、助学、督学"**三个方面引导帮扶
- 帮扶一段时间后**预警等级自动降级或取消**
- 形成"提前预警 → 精准帮扶 → 适时跟进"闭环

**其他**：广西师大独秀系统（AI + 大数据 + 区块链，动态成长全息档案）；北邮学科大模型（教师设计者 / 学生建构者 / 大模型陪练者三方协同）；华东师大 InnoSpark（知识图谱驱动的个性化）。

### 2.6 通用学情分析系统（功能基线）

多维度统计（平均分/最高/最低/标准差）、可视化图表（柱状/饼图/雷达）、智能教学建议、单个学生成绩分析与个性化学习建议、班主任辅导建议。

## 三、竞品共性结论（行业"标配"）

1. **标签化学生画像**是统一入口，维度普遍覆盖：学业、行为、生活（消费/门禁）、心理、第二课堂、就业
2. **分级预警**（蓝/黄/橙/红三级或四级）+ 可配置阈值 + 自动触发
3. **闭环干预**：预警 → 复核 → 帮扶 → 跟踪 → 降级/解除，并留痕形成台账
4. **数据下钻**：校 → 院 → 专业 → 班级 → 课程 → 学生
5. **多角色视图**：学生、教师、班主任/辅导员、学科负责人、院级、校级
6. **消息触达**：微信/短信通知 + 审批待办
7. **对接教务系统 API**，而非只做独立系统

### 行业公认痛点（竞品未能很好解决）

| 痛点 | 说明 |
|---|---|
| 数据孤岛 | 多源数据难打通，质量参差不齐 |
| 标签体系不标准化 | 各校自定义，难以复用 |
| 应用场景深度不足 | 多为"看板展示"，缺少行动闭环 |
| **依赖云端大模型** | 学生敏感数据上云，隐私与成本双重压力 |
| **预测结果不可解释** | 机器学习给出风险分，但不说明理由、不给建议 |
| 预警后无干预追踪 | 只"报"不"管"，缺乏效果评估 |

> 其中后 3 项正是本课题（Ollama 本地化 + LLM 与机器学习融合 + 预警建议一体化）的差异化切入点，也是创新点的立论依据，可直接写入论文 1.1/2.3 节。

## 四、功能增强清单（吸取竞品优势后新增）

> 标记说明：`【新增】`= 开题报告未明确、由竞品分析引入；`【强化】`= 开题报告已提及但需按竞品标准细化

### A. 学生画像与标签体系 【新增，高优先级】

竞品标配，开题报告未单列，建议作为系统核心模块。

- **五维画像卡**：学业力、学习投入、行为规律、发展潜力、风险等级
- **标签体系**：静态标签（生源地、专业、年级）+ 动态标签（出勤异常、挂科风险、偏科、进度滞后）自动打标
- **画像雷达图**：个人 vs 班级均值 vs 专业均值 三层对比
- **成长档案**：时序化的画像快照，支持回放与复盘

### B. 分级预警规则引擎 【强化，高优先级】

- **四级预警**：蓝（关注）/ 黄（提醒）/ 橙（警告）/ 红（严重），对标许昌学院黄橙红三级
- **规则引擎**：可视化配置阈值与规则组合（单指标阈值、多指标加权评分卡、趋势突变检测）
- **预警类型扩展**（对标新开普）：学业预警、出勤预警、作业预警、挂科预警、进度预警、心理/消费异常预警（预留）
- **预警去重与抑制**：同一学生同期同类预警合并，避免骚扰

### C. 预警干预闭环工单 【新增，最高差异化价值】

竞品的普遍短板，本系统重点补齐。

- 预警生成 → **指派责任人**（辅导员/导师）→ 帮扶记录（导学/助学/督学三类动作）→ 效果评估 → **自动降级或解除**
- **干预台账**：记录全部帮扶过程，支持导出
- **闭环率统计**：预警处理率、平均响应时长、降级率、复发率——直接作为论文"系统有效性"的量化论据

### D. 数据下钻分析 【新增】

- 校 → 院 → 专业 → 班级 → 课程 → 学生 逐层下钻
- 任一异常指标可点击穿透到明细清单

### E. 试卷/命题质量分析 【新增，论文亮点】

对标启明泰和，是多数毕设系统没有的差异化模块：
- 难度、区分度、得分率、标准差
- 题目-知识点映射，错题知识点归因
- 命题质量预警（难度失衡、区分度过低）

### F. 知识点掌握度与偏科分析 【新增】

- 知识点掌握热力图、偏科识别、强弱项对比

### G. 多角色工作台 【强化】

五种驾驶舱，各自的首页卡片与指标集不同：
学生端 / 任课教师端 / 辅导员（班主任）端 / 院级管理端 / 校级管理端

### H. 消息通知与待办中心 【新增】

- 站内信 + 待办任务（对标竞品"微信业务通知、审批待办"）
- 学业预警经 WebSocket/SSE 实时推送
- 邮件/企业微信 Webhook 可选扩展

### I. 大模型能力增强 【强化，课题创新核心】

| 能力 | 说明 | 竞品依据 |
|---|---|---|
| **AI 学情问答助手（RAG）** | 基于培养方案、课程大纲、校规文档做检索增强问答，引用原文出处 | RAG 范式 [4]，北邮学科大模型 |
| **预测结果自然语言解释** | SHAP 特征贡献 + LLM 转述为教师可读的归因说明 | 解决竞品"预测不可解释"痛点 |
| **一键生成学情报告** | 个人/班级/课程三档，导出 Word/PDF | 竞品"成长报告" |
| **个性化学习建议** | 按学生强弱项生成可执行建议清单 | 竞品"导学/助学/督学" |
| **提示词模板管理** | 模板版本化、变量注入、效果对比 | 工程化必备 |
| **多模型路由与降级** | Ollama 多模型（llama3.2 / qwen2.5）路由，失败自动降级 | 开题报告已列 |
| **AI 用量与审计** | Token 统计、调用日志、敏感词过滤 | 合规要求 |

### J. 数据接入与质量治理 【强化】

- **Excel 批量导入**（提供标准模板 + 校验报告）
- **教务系统 API 对接适配器**（预留接口 + Mock 实现）
- **模拟数据生成器**（一键生成演示用的学生/成绩/考勤/行为数据，毕设演示与测试必备）
- **数据质量校验**：缺失、越界、重复、一致性规则，输出质量报告
- **数据脱敏**：字段级脱敏开关，手机号/身份证掩码

### K. 模型管理与评估中心 【新增】

- 模型注册、版本管理、训练/评估记录
- 多模型指标对比看板（Accuracy / Precision / Recall / F1 / AUC / RMSE）
- 特征重要性展示、模型上线/回滚

### L. 校级可视化大屏 【新增】

- 学情总览驾驶舱：在校生规模、预警分布、预警趋势、学院排行、风险热力图

### M. 学生端自助模块 【新增】

- 个人学情雷达、目标设定（目标绩点）、学习资源推荐、成长时间轴

### N. 系统治理 【强化】

- JWT + RBAC 分级权限（学生/教师/辅导员/院系/管理员）
- **操作审计日志**（谁在何时查看了哪些学生敏感数据）
- 数据访问留痕，满足教育数据合规要求

## 六、优先级建议（按毕设交付风险排序）

| 优先级 | 模块 | 理由 |
|---|---|---|
| P0 必须有 | 认证鉴权、学情数据管理、学业预测引擎、四级预警、基础可视化、大模型报告生成 | 开题报告承诺的核心内容，缺一不可 |
| P1 强烈建议 | 学生画像标签体系、干预闭环工单、消息通知、多角色工作台 | 竞品标配，答辩时容易被提问"和已有系统有什么不同" |
| P2 加分项 | RAG 问答助手、预测可解释（SHAP）、试卷质量分析、数据下钻 | 论文创新点与亮点章节的素材 |
| P3 有余力 | 校级大屏、学生端自助、模型评估中心、企业微信通知 | 锦上添花，时间紧张时可降级为演示静态页 |

## 七、可直接用于论文的表述素材

1. **2.3 现有研究不足** 可补充："现有商业平台（如强智数智画像、启明泰和教研大数据）虽已实现多维画像与预警，但其预警多停留在'展示与通知'层面，缺乏预警—干预—评估的闭环机制；其分析能力以统计规则为主，缺少对预测结果的可解释说明；且系统多为云端部署或校内重型平台，难以在保护数据隐私的前提下低成本落地。"

2. **创新点** 可归纳为四点（与审核表一致，并补充闭环）：
   - 本地大模型私有化部署（数据不出本机、零调用成本）
   - 大模型与机器学习融合的学情预测机制（含预测可解释）
   - **"预测—预警—干预—评估"全链路闭环**（竞品普遍缺失，可作为最强创新点）
   - 三端统一架构
