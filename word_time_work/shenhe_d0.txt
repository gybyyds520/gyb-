| 课题意义、主要研究内容/设计目标 | 1.课题意义<br><br>本课题针对高校学情数据分散、分析依赖人工经验、学业预警不及时等现状，设计并实现一个基于本地大模型的高校学情预测分析系统。系统整合学生成绩、考勤、课堂表现与在线学习行为等多源学情数据，融合机器学习预测模型与Ollama本地大模型，实现学业成绩预测、学业风险预警、学情可视化分析与个性化学习建议生成；Ollama本地化部署保障学生数据隐私、降低使用成本；支持Web端、移动端（响应式网页版）与Electron桌面端多端使用，并面向学生、教师、辅导员与管理人员提供分级服务。创新点包括：本地大模型私有化部署、大模型与机器学习融合的学情预测机制、学业预警与个性化建议一体化服务、三端统一架构。<br><br>2.主要研究内容<br>（1）系统总体架构设计：前后端分离架构，Spring Boot 3.2.5、Vue 3、MySQL 8与Redis，支持Web端、移动端（响应式网页版）与Electron桌面端三端复用；（2）学情数据管理：学生信息、课程成绩、考勤记录、课堂表现与在线学习行为等多源数据的采集、清洗与统一存储；（3）学业预测与预警：基于逻辑回归、随机森林、XGBoost等算法的学业成绩预测模型与学业预警机制；（4）大模型学情分析：利用Ollama本地大模型实现学情文本理解、预测结果解释、学情报告自动生成与个性化学习建议；（5）可视化分析：学情总览仪表盘、成绩趋势分析与多维统计报表；（6）管理后台：用户管理、数据管理、预警规则管理与AI系统管理；（7）安全合规：JWT认证与鉴权、RBAC分级权限控制、数据脱敏与隐私保护；（8）测试体系：单元测试、集成测试与系统测试三层全覆盖，自动化测试用例1000个以上并全部通过。<br><br>3.主要设计目标<br>实现功能完整、安全健壮、运行稳定的高校学情预测分析系统，覆盖Web端、移动端（响应式网页版）与Electron桌面端三端；实现学业成绩预测与学业预警功能，预测结果准确可靠，为高校教学管理与学生帮扶提供数据支撑；完成自动化测试用例1000个以上并全部通过，系统全链路稳定运行。<br> |  |  |  |  |  |  |  |  |  |  |  |  |
